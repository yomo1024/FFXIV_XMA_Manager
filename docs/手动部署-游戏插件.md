> 里粘贴 `https://cdn.jsdelivr.net/gh/yomo1024/FFXIV_XMA_Manager@main/pluginmaster-cdn.json`

# 手动部署（不用 setup.bat）

`setup.bat` 只是"帮你复制文件"而已，手动做完全一样，而且更好排查。核心就一件事：

> **把 `2-plugin\ModBridge\` 里的 12 个文件，复制到 Dalamud 的 `devPlugins\ModBridge\` 目录里。**

---

## 第 0 步：先完全退出游戏

插件是 DLL，**游戏开着时文件是锁住的，复制一定失败**。
把游戏（包括 XIVLauncher 的游戏进程）全部关掉再动手。

---

## 第 1 步：找到你的 Dalamud `devPlugins` 目录

**办法 A（最可靠，推荐）**：进游戏 → 输入 `/xlsettings` → 切到 **Experimental** 标签页 →
找到 **Dev Plugin Locations**（开发插件目录）那一栏，**它列出的路径就是**。
顺手也可以点 `+` 把你自己放的目录加进去。

**办法 B（默认位置，国服优先）**：
1. 按 `Win + R`，输入 `%APPDATA%`，回车
2. **国服（XIVLauncherCN）优先找 `XIVLauncherCN`**；国际服用 `XIVLauncher`
3. 里面的 `devPlugins` 就是；**没有就自己新建一个**叫 `devPlugins`

> ⚠ **国服注意**：目录是 `%APPDATA%\XIVLauncherCN\devPlugins`，**不是** `XIVLauncher`。
> 拷错目录的表现就是：游戏里 `/xlplugins` 里根本看不到它，而且有些启动器还会把它清掉。
> 最保险还是用**办法 A** 从 `/xlsettings` 里核对/登记真实路径。

最终目标路径长这样（两种都行）：

```
C:\Users\<你的用户名>\AppData\Roaming\XIVLauncher\devPlugins\ModBridge\
```

> 小技巧：在文件资源管理器地址栏直接粘贴 `%APPDATA%\XIVLauncher\devPlugins` 回车即可跳过去。

---

## 第 2 步：复制文件

1. 解压部署包，进入 `2-plugin\ModBridge\`
2. **全选里面 12 个文件**（注意：是**文件**，不是这个文件夹本身）
3. 粘贴到 `...\devPlugins\ModBridge\`（`ModBridge` 这层如果没有就先新建）

要复制的 12 个文件：

```
ModBridge.dll                 ← 插件本体（必须）
ModBridge.json                ← 清单（必须）
ModBridge.deps.json
Penumbra.Api.dll
Luna.dll
System.IO.Hashing.dll
Microsoft.Extensions.DependencyInjection.dll
Microsoft.Extensions.DependencyInjection.Abstractions.dll
Microsoft.Extensions.Logging.dll
Microsoft.Extensions.Logging.Abstractions.dll
Microsoft.Extensions.Options.dll
Microsoft.Extensions.Primitives.dll
```

**⚠ 最常见的错**：套了两层。正确的是

```
✅ devPlugins\ModBridge\ModBridge.dll
❌ devPlugins\ModBridge\ModBridge\ModBridge.dll
❌ devPlugins\ModBridge.dll              （文件直接扔在 devPlugins 里也不行）
```

复制完在 `devPlugins\ModBridge\` 里应该正好看到上面 12 个文件。

---

## 第 3 步：进游戏启用

1. 启动游戏
2. 输入 `/xlplugins` → 切到 **Dev Plugins** 标签 → 找到 **Mod Bridge** → 点 **启用**
3. 输入 `/modbridge`，应该弹出插件窗口（能看到端口、Token、Penumbra 状态）

**确认加载成功**（任选其一）：
- `/xllog` 里能看到一行：`[ModBridge] Penumbra API 5.x, mods 目录: ...`
- 或命令行里执行：
  ```bat
  curl http://127.0.0.1:42100/ping
  ```
  返回里必须有 **`"version":"0.2.7"`**（版本号比它旧，说明拷贝没成功、跑的还是旧 DLL）

---

## 第 4 步：启动管理器并配对

1. 双击 `1-manager\ModManagerWeb.exe`（会在后台起服务）
2. 浏览器打开 `http://127.0.0.1:8765`
3. 设置 → 「游戏内插件」→ 点 **自动配对**（它直接读插件的配置文件拿端口和 Token）
   - 自动配对失败也没关系：把 `/modbridge` 窗口里的 Token 复制过来，手动填 + 点「测试连接」

---

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 复制时报"文件正在使用" / 权限错误 | 游戏没关干净：关游戏 + 关 XIVLauncher，再复制；或先删掉 `devPlugins\ModBridge` 整个文件夹再拷 |
| `/xlplugins` 里看不到 Mod Bridge | ① 目录层级错了（见第 2 步 ⚠）② 没重启游戏 ③ Dalamud 的 dev 目录不是默认那个 → 用**办法 A** 从 `/xlsettings` 核对路径 |
| 启用了但 `/ping` 说 0.1.0 | 你拷的还是旧 DLL：确认来源是**新解压**的部署包里的 `2-plugin\ModBridge\` |
| `/modbridge` 窗口里 Penumbra 未连接 | 游戏里 Penumbra 没启用/没加载完：`/penumbra` 打开一次，再回窗口点「重新探测 Penumbra」 |
| 想彻底卸载 | 删掉 `devPlugins\ModBridge` 整个文件夹，重启游戏 |

## 附：命令行复制（懒人版）

把 `<用户名>` 换成你的，一行搞定（**游戏必须已关闭**）：

```bat
mkdir "%APPDATA%\XIVLauncher\devPlugins\ModBridge"
xcopy "2-plugin\ModBridge\*" "%APPDATA%\XIVLauncher\devPlugins\ModBridge\" /E /I /Y
```

（`2-plugin\ModBridge\` 是相对路径，所以**必须在解压出来的包目录里**执行；如果你是从压缩包里直接双击脚本，先解压到文件夹再执行。）
