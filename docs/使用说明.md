# FFXIV Mod 工具包 v1.0

一个压缩包，三样东西，各用各的、配合起来用：

| 文件夹 | 是什么 | 装在哪 |
|---|---|---|
| `1-Manager-管理器` | **ModManager**（Web 管理器）：扫目录 / 入库 / 编辑 / 生成 Excel 汇总表 / 分类管理 / 下载工作台 | 任意位置双击即用（绿色版） |
| `2-ModBridge-游戏插件` | **ModBridge**（Dalamud 游戏内插件）：管理器里点「安装到游戏」→ 游戏内确认 → 装进 Penumbra 并即时生效（带预览图） | 游戏侧（一次性部署） |
| `3-BrowserExt-浏览器拓展` | **浏览器拓展**：在 XIVModArchive 的 Mod 页面右下角一键「下载并导入管理器」 | 你自己的浏览器（一次性加载） |

**核心思路**：浏览器负责**下载**（用你已登录的身份），管理器负责**接住并入库**（写 地址.txt / 自动编号 / 抓封面 / 重扫 / 导 Excel），游戏插件负责**把 Mod 装进游戏**。全程只有一个浏览器，不用再登一次。

---

## 一、装（一次性）

### 1. 管理器（必须，最简单）
把 `1-Manager-管理器` 整个文件夹放到你喜欢的位置（例如 `G:\Games\FFXIV\Soft`），双击里面的 **`启动Web版.bat`**，
浏览器打开 `http://127.0.0.1:8765` 即可。第一次进「设置」把 **Mod 根目录 / 汇总表 Excel** 指好。

### 2. 浏览器拓展（强烈建议）
1. 地址栏输入 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 右上角打开 **开发者模式**
3. 点 **「加载已解压的扩展程序」** → 选 `3-BrowserExt-浏览器拓展` 这个文件夹
4. 扩展列表里点「固定」，工具栏就有图标了

### 3. 游戏插件 ModBridge（想要"点一下就装进游戏"就装）

**最省事的办法：用 Dalamud 自定义插件源（可自动更新）**

1. 游戏内 `/xlsettings` → **Experimental** → **Custom Plugin Repositories**
2. 粘下面任意一条，点 `+` 添加（**国内一般选第二条更稳**）：
   ```
   https://raw.githubusercontent.com/yomo1024/FFXIV_XMA_Manager/main/pluginmaster.json
   https://cdn.jsdelivr.net/gh/yomo1024/FFXIV_XMA_Manager@main/pluginmaster-cdn.json
   ```
3. 保存 → `/xlplugins` → 找到 **Mod Bridge** → 安装 → 启用
4. 以后插件有更新会自动出现在更新列表里

**或者手动部署**（不想加插件源时）：
先**关掉游戏**，然后：
- 推荐：运行 `2-ModBridge-游戏插件\setup.bat`（自动找 XIVLauncherCN / XIVLauncher，把插件放进 devPlugins）
- 或者：看 `2-ModBridge-游戏插件\手动部署-游戏插件.md` 手动放（那个文档里有 12 个文件的清单和常见坑）

装完启动游戏 → `/xlplugins` → Dev Plugins → 启用 **Mod Bridge** → `/modbridge` 能看到端口和 token 就成了。
（如果插件列表里没有：游戏内 `/xlsettings` → Experimental → **Dev Plugin Locations** 把这个文件夹加进去 → 重启游戏）

## 二、日常怎么用（两条路，选你顺手的）

### 路线 A：浏览器拓展（推荐，最省事）
1. 在**你自己的浏览器**里打开 Mod 页面（`xivmodarchive.com/modid/…`）
2. 右下角面板选好 **分类 / 类型** → 点 **「⬇ 下载并导入管理器」**
3. 浏览器开始下载 → 管理器自动接住并入库 → 想装进游戏就点「安装到游戏」

### 路线 B：书签小工具
1. 管理器「下载工作台」里把那个书签拖到书签栏
2. 在 Mod 页面点一下书签 → 信息（名称/作者/封面/直链）送到管理器
3. 回工作台点 **「⬇ 用我自己的浏览器下载 → 自动入库」**

> NSFW 的 Mod 只有**你已登录的浏览器**看得到下载链接 —— 所以这两条路都刻意"用你自己的浏览器"，
> 不需要在别的地方再登录一次（内置浏览器只是可选的备用方式）。

## 三、常见问题

| 现象 | 处理 |
|---|---|
| 管理器打不开 / 页面白屏 | 先跑 `启动Web版.bat`；端口被占会自动换端口，看 bat 窗口里打印的地址 |
| 拓展面板显示「连接不到管理器」 | 管理器没启动；或端口不是 8765 → 点扩展图标填端口 → 「连接」 |
| 拓展面板「没找到下载链接」 | 在这个浏览器里登录 XIVModArchive 后刷新页面（NSFW 必须登录才可见） |
| 点了下载，管理器没入库 | 确认浏览器下载目录和管理器「下载目录」一致（管理器会自动读你浏览器设置的下载目录，通常已经一致） |
| 游戏里点安装没反应 | 插件没启用 / 没重启游戏 / 管理器里「设置 → 游戏插件 → 自动配对」+「测试连接」 |
| 预览图不显示 | 装完后在管理器点「补封面到游戏」；Penumbra 侧预览由插件绘制 |

## 四、版本

- 管理器 ModManager **v2.1**（构建时间看侧栏页脚 `v2.1 · HH:MM`）
- 游戏插件 ModBridge **v0.2.6**（管理器要求插件 ≥ v0.2.6，版本旧了会明确拦住并提示）
- 浏览器拓展 **v1.0.0**

三样东西都只跟本机 `127.0.0.1` 通信，不上传任何数据。
