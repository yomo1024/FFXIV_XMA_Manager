# 搬到新电脑（迁机指南）

> **一句话**：新电脑上装好程序 → 恢复一份备份（勾「套用备份里的配置」）→ 插件配对一次 → 完事。
> 已归档的 Mod 载荷不用下载，需要装进游戏时管理器会自动从云端取回。

## 备份包里有什么

| 包内路径 | 内容 | 迁机必要 |
|---|---|---|
| `mods/` | Mod 文件夹（元数据 + 预览图 + 画廊图 + `地址.txt`） | ✅ |
| `index/mod_manager.db` | 索引库（29 条 Mod 的标签 / 影响替换 / 站点版本 / 云端状态…） | ✅ |
| `index/mod_manager.json` | **配置**（云盘 Cookie、分类顺序、界面偏好、各类目录路径…） | ✅ |
| `excel/*.xlsx` | Mod 信息汇总表 | ✅ |
| `迁移到新电脑.txt` | 就是这份指南（纯文本，包内自带） | — |

**不在包里**：Mod 载荷（`.pmp`/`.zip`）—— 长期副本在夸克网盘，需要时会自动取回；
内置浏览器的登录态（新电脑点一次「同步登录状态」即可）。

## 新电脑上的步骤

1. **装程序**：解压部署包 `XMA-Manager-v*.zip` 到任意目录（建议非系统盘），双击 `ModManagerWeb.exe`，
   浏览器会自动打开管理器页面。
2. **恢复备份**：把旧电脑上导出的备份 zip 拷过来 → 管理器「备份 / 恢复」→ 点该备份的**恢复**：
   - 勾 **Mod 文件夹** + **索引库 + 汇总表**
   - 勾 **套用备份里的配置**（迁机就靠它）
   - 冲突方式选 **跳过（最保险）**
3. **路径类设置**：Mod 根目录 / 汇总表 / 下载目录 / 暂存目录 / Penumbra 目录 / 备份目录 ——
   新电脑上如果和旧电脑不一样，恢复时会**保留新电脑当前的设置**并把差异列出来；
   照提示到「设置」里指到新电脑的对应目录即可。
   （如果新电脑上恰好是同样的盘符和路径，就会自动套用，什么都不用改。）
4. **云盘**：夸克 Cookie 在配置里一起带过来了 → 「设置 → 云存储 → 测试连接」确认一下。
   已归档的载荷不用下载；详情「文件」页签能看到云端文件，点名字就能下载。
5. **游戏插件**：Dalamud 里装好 ModBridge（自定义插件源或手动部署，见 `docs/使用说明.md`），
   然后管理器「设置 → 游戏插件」点一次**测试连接 / 自动配对** ——
   插件在新电脑上会生成新的 Token，配对后就能「安装到游戏」。
6. **浏览器拓展**（可选）：按 `docs/浏览器拓展-安装说明.md` 加载一次，端口填 `8765`。

## 常见问题

| 现象 | 处理 |
|---|---|
| 恢复后 Mod 列表是空的 | 索引库没勾或没恢复成功 → 重新恢复一次并勾「索引库 + 汇总表」，或点「重新扫描」 |
| Mod 都在，但点「安装到游戏」报没载荷 | 正常：载荷在云端，装的时候会自动取回，第一次稍慢 |
| 预览图不显示 | 首次浏览会自动生成缩略图缓存，稍等或点进详情看一眼 |
| 网盘提示 Cookie 失效 | 「设置 → 云存储 → 体检」看缺哪个字段，重新从浏览器复制一次 Cookie |
| 插件显示未连接 | 「设置 → 游戏插件 → 测试连接」重新配对；确认插件已启用、端口 42100 |

## 反向操作：从新电脑回到旧电脑

同一套流程，方向反过来即可（备份包里带的是**配置**，不是"哪台电脑"）。
