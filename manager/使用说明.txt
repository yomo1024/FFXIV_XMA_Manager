FFXIV Mod 管理工具  使用说明
================================================================

【目录分工】
  程序（本目录）  G:\Games\FFXIV\Soft
  数据            G:\Games\FFXIV\MOD\202609          （Mod 源文件）
                  G:\Games\FFXIV\MOD\Mod信息汇总表.xlsx （生成的汇总表）

【怎么用】
  双击本目录里的  ModManager.exe   （或双击「启动Mod管理工具.bat」）

  界面从上到下：菜单栏 → 工具栏 → 路径行 → 左列表 / 右详情 → 状态栏

  ● 菜单栏：文件 / Mod / 网站 / 视图 / 设置 / 帮助
      （以后新增的功能都会挂在这里，功能变多也不会挤）
  ● 工具栏（最常用的 6 个）：
      添加 Mod… ｜ 编辑选中… ｜ 删除选中 ｜ 下载工作台… ｜ 扫描目录 ｜ 生成 Excel ｜ 扫描并生成 Excel
      右边「更多 ▾」里是和菜单栏一致的全部功能
  ● 路径行：显示当前 Mod 目录 / Excel，点「设置…」可改（预览图宽度也在这里）
  ● 左半边：用「分类 + 类型(SFW/NSFW) + 搜索」筛选列表
  ● 右半边：预览图 + 详情（Mod 地址、文件夹可直接点开）+ 快捷按钮
      编辑… / 打开文件夹 / 复制路径 / 补预览图 / 删除
  ● 底部状态栏：左边是运行状态，右边是统计（共 N 条 ｜ 显示 M 条 ｜ 各分类数量）
  ● 快捷键：F5 = 扫描　Ctrl+N = 添加　Delete = 删除　双击列表项 = 打开所在文件夹
  ● 列表上点右键：编辑 / 打开所在文件夹 / 复制路径 / 补预览图 / 删除
  ● 窗口大小和位置会自动记住，下次打开还是这样

【添加 Mod】
  点「添加 Mod…」，填这几项（窗口会显示在主窗口正中间）：
    来源        点「选文件夹…」选 Mod 文件夹，或点「选压缩包…」选 zip/7z/rar/pmp
    分类        衣服 / 饰品 / 武器 / 皮肤 …（可直接输入新分类）
    类型        SFW 或 NSFW                     ← 会建成 分类\SFW 或 分类\NSFW
    子分类目录   可留空；皮肤纹身那种就填 纹身    ← 会建成 皮肤\NSFW\纹身
    作者       会自动从来源名字里识别，可改
    Mod 名称    同上
    序号        留空 = 自动取该目录下一个可用号（现有最大 +1）
    Mod 地址    可选，填了会自动写成该 Mod 的 地址.txt
    复制/移动    复制=原文件保留；移动=原位置不再保留
    ☑ 导入后自动重新生成 Excel
    ☑ 自动把封面存为该 Mod 的预览图   ← 勾上后导入完就有预览图
  确定后工具会自动建好文件夹、放好文件、更新索引、重生成 Excel。

【自动分配序号】（菜单 文件 → 自动分配序号…）
  用途：删过 Mod 之后序号会有空号（比如 1、2、5），这里能重排成连续的。
  ● 选分类（可「全部分类」）+ 子分类 + 起始序号（默认 1）→ 点「预览」看对照表 →「应用」
  ● **每个分类各自编号**：选「全部分类」时，衣服从 1 排、饰品也从 1 排，不会混在一起
  ● 只改文件夹名（Mod 内容不动），改完自动重新生成 Excel

【重复 Mod 检查】（菜单 文件 → 查重…）
  按两种方式找重复：
    · 同一个 Mod 地址（modid 一样 → 基本可以确定是重复的）
    · 作者 + 名称相同（疑似重复）
  列出分组后可以「打开所在文件夹」核对，确认多余的那条点「删除选中（回收站）」。

【安装检查】（菜单 文件 → 安装检查…）
  用途：看哪些 Mod 还没装进游戏（Penumbra）。
  ● 先指定「安装目录」= Penumbra 的 Mods 目录，一般是：
        %APPDATA%\XIVLauncher\pluginConfigs\Penumbra\Mods
    也可以在「设置 → 路径设置… → Mod 安装目录」里填。
  ● 工具拿安装目录里每个文件夹的名字，和 Mod 的名称/作者比对
    （支持 "名称_作者" 这种 Penumbra 命名），得出每条的安装状态：
        主列表最后一列「是否安装」：已安装 ／ 未安装 ／ ? = 还没设置安装目录
        ● 列表按安装状态上色：已安装 = 淡绿色底，未安装 = 白色底
          （选中的那一行会暂时变成高亮色，取消选中就恢复）
        窗口里那一列也叫「是否安装」，值是 已安装 / 未安装
  ● 窗口里有：重新扫描、打开安装目录、复制未安装清单、只看未安装

【分类 / 子分类】
  分类 = Mod 根目录下的文件夹（衣服 / 饰品 / 武器 / 皮肤 / 特效 / 套装 / 裤子 / 鞋子 / 基础 / UI …）
  子分类 = 分类里的下一级目录（如 皮肤\纹身、武器\双蛇）

  ● 菜单「设置 → 分类管理…」（或「更多 ▾ → 分类管理…」）里可以：
      新建分类        建一个分类文件夹（自动带上 SFW / NSFW 两个子目录）
      新建子分类      在当前选中的分类下建子分类（默认算 SFW，可在「编辑」里改成 NSFW）
      重命名          分类 / 子分类都能改名（里面 Mod 的路径会跟着更新）
      删除（空）      只允许删空目录，会移入回收站；还有 Mod 的目录不让删
      上移 / 下移     调整分类顺序（影响分类下拉框和 Excel 工作表顺序）
  ● 主界面列表新增「子分类」列，筛选条也多了「子分类」下拉（选了分类就只列它的子分类）
  ● 「添加 Mod」「编辑 Mod」里的 分类 / 子分类 都是下拉，可直接选也能手输新名字
  ● Excel：某个分类里如果有子分类，那张工作表会自动多一列「子分类」

【编辑 Mod】（改名 / 换分类 / 换类型 / 移动 / 改地址）
  选中一条 → 点「编辑选中」，窗口里会显示「当前文件夹」和「将变为」，
  下方可改：分类、类型、子分类目录、作者、Mod 名称、序号、Mod 地址。
    * 换了分类/类型/子目录时，序号会自动改成目标目录的下一个可用号；
      只改名字时序号保持不变。
    * 地址栏清空 = 删除该 Mod 的 地址.txt。
  保存后工具会自动移动文件夹、更新索引、重生成 Excel。

【从网站下载 Mod 到库里】
  xivmodarchive.com 有 Cloudflare 人机验证，程序无法直接抓取（会 403），
  所以工具内置了一个「真实浏览器」窗口，由它去过验证，工具只负责读取和搬运。

  ● 方式 A（推荐，能自动带上网址和封面）
    1) 工具栏「下载工作台…」→ 点「打开/显示浏览器」
       会弹出一个独立的 Edge/Chrome 窗口（工具专用配置；第一次请在窗口里登录一次，之后就保持登录）
    2) 在浏览器里挑 Mod，点进详情页（网址形如 .../modid/169359）
    3) 回工作台点「抓取当前页面」→ 自动读出 网址 / 名称 / 作者，并把封面图抓下来（右下角预览）
       （很快，约 0.1 秒；只有首次打开页面/过人机验证要等几秒）
    4) 点「下载到暂存区」→ 这一下会**自动先抓一次页面（地址+封面），再去点下载**，
       等文件下完后自动搬进暂存目录。列表里那行会显示「封面 ✔」
       （下载慢是站点带宽问题，状态栏有计时；**不想等了就点「取消下载」**）
    5) 在下面列表里选中它 → 「导入选中…」→ 选分类/类型 → 确定
       会自动填好 Mod 地址，并把封面图保存成该 Mod 的预览图（Excel 里就有图了）
    6) 攒一批后点「扫描并生成 Excel」

  ● 方式 B（用你自己的浏览器）
    在自己浏览器里正常登录、下载 → 工作台点「刷新」→ 选中 →「导入选中…」
    （这种方式不会自动带网址和封面）

  ● 已经入库的 Mod 想补封面：主界面选中它 → 点「补预览图」
    （或右键菜单「补预览图（按地址抓封面）」）→ 工具会用内置浏览器打开它的 Mod 页面，
      抓封面存成该 Mod 的预览图，并重新生成 Excel。已经有同名封面时不会覆盖。
  ● 下载慢是站点带宽问题，工具会一直等（状态栏有秒数），期间别关窗口
  ● 工作台监视两个文件夹：下载目录 + 暂存目录，都能在「设置 → 路径设置…」里改
  ● 默认只列常见 Mod 文件（.pmp/.zip/.7z/.rar/.ttmp2…）；
    想看到别的格式就勾「显示所有类型的文件」；没下完的 .crdownload 等会自动忽略
  ● 内置浏览器用哪个可以自己选：「设置 → 路径设置… → 内置浏览器」
    会自动探测 CentBrowser(百分) / Chrome / Edge / Brave / Vivaldi / Opera / 360极速 等，
    也可以「浏览器程序」那里手动指定任意 Chromium 内核浏览器。
  ● 每种浏览器用各自的配置目录（程序目录\browser_profile\<浏览器>_<哈希>）和 9333 端口，
    和你日常浏览器互不影响；换账号/出问题直接删掉 browser_profile 整个文件夹再登录一次。
  ● 站点有人机验证：打开后可能要等几秒（标题显示「请稍候」），工具会自己等；
    如果一直不过，就在浏览器窗口里点一下验证框，再回来点「抓取当前页面」。
  ● 下载速度取决于网络，工具会一直等到文件下完（状态栏有秒数），期间别关窗口。
  ● 「下一页」按钮可以翻浏览列表；「打开暂存文件夹」直接去看下载好的文件

【删除 Mod】
  选中一条 → 点「删除选中」→ 确认。
  文件夹会**移入回收站**（不是永久删除），需要时可以还原。

【打包备份】（工具栏「打包备份…」，或菜单 备份 → 打包备份…）
  把整个 Mod 库打成一个 zip，换电脑 / 重装 / 手滑删错时能整体还原。

  备份内容（可勾选）：
    · Mod 文件夹           分类 / Mod / 预览图 / 地址.txt，整个 Mod 根目录（会比较大）
    · 索引库 + 汇总表       mod_manager.db + Mod信息汇总表.xlsx + 配置（很小，建议勾上）
    · 压缩                 体积略小但慢很多；Mod 本身多半已是压缩包，一般不用勾

  保存位置：默认 程序目录\backup\Mod备份_<根目录名>_<时间>.zip，可以改。
  打包时窗口上有进度条，可以点「取消」（半成品文件会自动删掉）。
  备份文件列表在 菜单 备份 → 打开备份文件夹 里看。

【导入备份】（工具栏「导入备份…」，或菜单 备份 → 导入备份…）
  挑一个备份 zip，窗口会先告诉你里面有什么：备份时间、多少个 Mod、多少文件、多大、
  包含哪些分类。然后勾选要恢复的内容：

    恢复内容：
      · Mod 文件夹          解压回 Mod 根目录
      · 索引库 + 汇总表      一般不用勾 —— 恢复完会自动重扫索引并重新生成 Excel

    如果已经存在同名的 Mod：
      · 跳过（最保险）      已存在的文件夹一个文件都不动，只补齐缺的（推荐）
      · 覆盖                旧的整个文件夹先移入回收站，再写回备份里的版本
      · 另存一份            文件夹名后面加「(备份恢复)」，两个都留着

  注意：覆盖前会把当前索引库 / 汇总表也另存到 backup\ 目录一份，误操作还能翻回来。
        恢复完会自动「重新扫描 + 重新生成 Excel」，列表和表格立刻就是最新的。

【命令行】（可选，需要已安装 Python；exe 同样支持）
  ModManager.exe run                     扫描 + 生成 Excel（最常用）
  ModManager.exe check                   检查
  ModManager.exe stats                   统计

  ModManager.exe add --src "D:\下载\xxx" --category 皮肤 --zone NSFW --subdir 纹身
  ModManager.exe add --src "...\mod.zip" --category 衣服 --addr https://... --move

  ModManager.exe edit --target "<Mod 文件夹>" --zone NSFW --seq 1
  ModManager.exe edit --target "<Mod 文件夹>" --name "新名字" --addr https://...
  ModManager.exe edit --target "<Mod 文件夹>" --addr ""      （清空地址）

  ModManager.exe delete --target "<Mod 文件夹>" --yes
      （不加 --yes 只提示不删；加 --permanent 则不进回收站）

  ModManager.exe backup                  完整备份（Mod 文件夹 + 索引库 + 汇总表）
  ModManager.exe backup --only meta      只备份索引库 + 汇总表（几 MB，秒完成）
  ModManager.exe backup --compress       备份时压缩（慢，体积略小）
  ModManager.exe backups                 列出已有的备份
  ModManager.exe restore --src "<备份.zip>"                 恢复（已存在就跳过）
  ModManager.exe restore --src "..." --mode overwrite --yes  覆盖已存在的
  ModManager.exe restore --src "..." --only meta             只恢复索引库+汇总表

【整理规则】（与之前手工整理的一致）
  分类       Mod 根目录下的一级目录（衣服 / 饰品 / 武器 / 皮肤 …）
  序号       文件夹名前缀数字，如 "1.[Arte] Neolithe Bodystocking" -> 1
  作者       文件夹名中括号里的内容
  Mod名称    中括号后面的名称（会去掉开头多余的 "- "）
  NSFW/SFW   路径里出现的 SFW / NSFW 目录名；没有就默认 SFW（如 武器\双蛇\…）
  Mod地址    文件夹里 地址.txt 的第一行；找不到就在子文件夹里递归找
  预览图     优先"与文件夹同名"的图片（同级目录 > 文件夹内），
             其次 [作者] 名称.jpg / 名称.jpg，最后才用文件夹里任意图片

【文件说明】
  ModManager.exe        打包好的程序（双击即用，不需要 Python）
  mod_manager.py        源代码（用 Python 直接跑就是它）
  app.ico               程序图标
  启动Mod管理工具.bat     启动器
  build_exe.bat         重新打包成 exe（双击即可，生成 ModManager.exe）
  使用说明.txt            本文件
  mod_manager.json      配置：Mod 根目录、Excel 输出路径、缩略图宽度等
  mod_manager.db        本地索引库（SQLite，删掉会自动重建）
  .thumb_cache\         缩略图缓存（自动生成，可删）
  backup\               备份目录：生成 Excel 前的自动备份（最近 5 份），
                        以及「打包备份」生成的 Mod备份_xxx.zip
  build\                打包中间文件（可删，删了下次打包慢一点）
  mod_manager.log       运行日志（出错时先看它）

【小贴士】
  * 加完新 Mod 只要点一次「扫描 + 生成 Excel」，没变动的图片会复用缓存，很快，
    Excel 也不会变大（预览图会先压到 800px 再嵌入，整表约 2MB）。
  * 想让某张图成为预览图：把它命名成和 mod 文件夹同名
    （文件夹是 7.[Ruby Blaire] Wisp 1.1，就在它同级放一张 7.[Ruby Blaire] Wisp 1.1.jpg），
    工具会优先用它，避免误用纹理/透明底 PNG。
  * 改预览图大小：编辑 mod_manager.json 里的 "thumb_width"（图片像素宽度）
    与 "preview_px"（Excel 里的显示尺寸）。
  * Excel 是"生成物"，手改 Excel 下次生成会被覆盖；
    要改内容请用工具，或改文件夹结构后重新生成。
  * 换电脑/重装：把 Soft 目录和 202609 一起拷走，再把 mod_manager.json 里的
    两个路径改对即可；对方机器不需要装 Python。
