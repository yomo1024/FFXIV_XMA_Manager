# 浏览器扩展：FFXIV Mod 管理器助手（安装说明）

这个扩展让**你自己的浏览器**（已登录 XIVModArchive 的那个）直接跟本地的 Mod 管理器配合：
在 Mod 页面右下角出现一个小面板，一键即可「下载并导入」。

**全程不需要第二个浏览器**：下载用的是你当前这个浏览器（带着你的登录态，NSFW 也能下），
管理器只负责在下完那一刻把文件接住、入库（写 地址.txt / 自动编号 / 抓封面 / 导 Excel）。

---

## 一、安装（一次性，约 30 秒）

1. 打开浏览器的扩展管理页
   - 地址栏输入：`chrome://extensions`（Chrome / CentBrowser / Edge 用 `edge://extensions`）
2. 打开右上角的 **「开发者模式」** 开关
3. 点 **「加载已解压的扩展程序」**
4. 选择这个文件夹（整个文件夹，不是里面的文件）：
   `4-browser-ext`（部署包里就是它；桌面上也放了一份 `FFXIV-Mod-Manager-Ext`）
5. 看到「FFXIV Mod 管理器助手 1.2.1」出现即成功（扩展列表里可以「固定」到工具栏）

> **1.2.1 修了什么**：面板里「子分类」候选一直显示 `[object Object]`（后端返回的是对象，
> 旧代码直接 `String()` 了）；分类根下的子分类（比如 `武器\双蛇`）因此完全选不到。
> 现在能正确列出所有子分类名。装新版：覆盖文件夹后在 `chrome://extensions` 点一下刷新即可。

> 想卸载：扩展管理页里点「移除」即可，不留任何东西。

## 二、使用

1. 先启动管理器（双击 `启动Web版.bat`，或运行 `ModManagerWeb.exe`）
2. 在**你自己的浏览器**里打开任意 XIVModArchive 的 Mod 页面（`.../modid/数字`）
3. 页面**右下角**会出现小面板，显示 名称 / 作者 / 是否找到下载链接；面板里的「标签」和「影响/替换」会自动带出站点上的内容（可改）
4. 选好「分类 / 类型」，点 **「⬇ 下载并导入管理器」**
   - 浏览器开始下载（用它自己的登录态）
   - 管理器自动等到文件落地 → 入库
   - 进度看管理器的任务进度条；想中途放弃就点「取消」
5. 只想登记信息、稍后再下？点 **「只送信息到管理器」**，然后到管理器的「下载工作台」处理

## 三、常见问题

| 现象 | 处理 |
|---|---|
| 面板显示「连接不到管理器」 | 管理器没启动（先点「启动Web版」）；或端口不是 8765 —— 点扩展图标，在弹窗里填端口 → 「连接」 |
| 面板说「没找到下载链接（可能要登录）」 | 在这个浏览器里登录 XIVModArchive 后再刷新页面 |
| 分类下拉是空的 | 管理器的「分类管理」里先建好分类；或者直接不选（会先进「待导入」） |
| 下载了但没入库 | 确认浏览器下载目录和管理器的「下载目录」是同一个（管理器会自动读你浏览器设置的下载目录，一般已经一致） |
| 面板不见了 | 刷新页面；或点扩展图标确认扩展已启用 |

## 四、它到底做了什么（透明说明）

- 读：只读当前 Mod 页面的 名称/作者/封面/画廊图/下载直链（不读历史、不读其他站点）
- 送：把这些信息 POST 给本机 `127.0.0.1:8765`（只有本机能访问）
- 下：用浏览器自带的下载接口下载那个直链（等价于你手动点下载按钮）
- 不收集、不上传任何数据到外部服务器
